# Rockumentary

An interactive scroll-story map of rock music in Bangalore, from the colonial dance halls of the 1930s to today's festivals and live-music venues.

Scroll the story and the map flies to the places where it happened: eight chapters, archival photos, "Did you know?" facts, first-hand Voices, concert tickets with setlists, and pins for dance halls, schools, hangouts, cabaret bars and venues.

## Run it

Open `index.html` in a browser, or serve the folder with any static host (GitHub Pages works). Photos live in `media/images/`.

- Explore mode: the "Explore the map" button.
- Editor (move pins, copy data): add `#edit` to the URL.
